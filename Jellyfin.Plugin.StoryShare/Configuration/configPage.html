Sharing

Puts a share icon next to Play on movie, show and album pages. Reload the web client after saving. Nothing is written to disk, so this needs no file permissions and survives Jellyfin server updates.
Needed for share links to work off your network. Leave empty and links use the address the browser reached the server on, which only works on your LAN.

Performance

The same card is usually asked for twice — once for the preview in the dialog, once when the link is opened — and an animated Vinyl card takes the better part of half a minute to draw and encode. Cards are dropped automatically when the item's metadata or these settings change.
Least recently used cards are dropped first. A still card is a few hundred KB; a video is one to three MB.
