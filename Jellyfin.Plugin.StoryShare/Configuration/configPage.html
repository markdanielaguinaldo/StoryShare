Post directly to Instagram

Optional. Instagram offers no API for posting to a personal account's story, so this needs a Business or Creator account linked to a Facebook Page, and a long-lived token from a Meta app with the instagram_basic and instagram_content_publish permissions. Without it, use the Story button's Download / Open-on-phone flow instead.
